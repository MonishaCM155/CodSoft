# CODSOFT Data Science Internship

This repository contains the projects completed as part of the CODSOFT Data Science Internship. The projects demonstrate data preprocessing, exploratory data analysis, machine learning model development, and performance evaluation across various real-world datasets.

## Projects Included
- Titanic Survival Prediction
- Movie Rating Prediction with Python
- Iris Flower Classification
- Sales Prediction Using Python
- Credit Card Fraud Detection

## Skills Applied
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning
- Model Evaluation
- Data Visualization

The objective of these projects is to gain practical experience in applying data science and machine learning techniques to solve prediction and classification problems.
